# 1. Release Summary

Provide a concise summary of the Release Plan.

The summary should communicate the purpose of the release and the value it intends to deliver without describing implementation activities.

---

# 2. Strategic Context

Describe how this release supports:

- the Product Vision;
- approved Product Decision Records;
- the Product Roadmap; and
- the Milestone Plan.

Explain the strategic context for the release.

---

# 3. Release Scope

Document the scope of this release.

For the release, describe:

- Release Name
- Description
- Product Capabilities
- Supported Milestone(s)
- Included Epics
- Delivery Priority
- Target Release Window (optional)

The Release Plan defines the intended Product scope for the release rather than implementation activities or Engineering delivery commitments.

---

# 4. Release Plan Readiness

Describe the rationale supporting Release Plan readiness.

Include significant considerations such as:

- scope completeness;
- dependency readiness;
- business readiness;
- operational readiness; and
- customer readiness.

---

# 5. Assumptions

# 6. Constraints

# 7. Risks

Document significant risks that may affect successful delivery of the release.

---

# 8. Success Characteristics

Describe the characteristics that indicate a successful release.

Focus on delivered customer and business value rather than implementation activities.
