# Epic Refinement Checklist

## 1. Purpose

This checklist assists participants in evaluating whether an Epic Refinement has been completed in accordance with the Collaboration Principles and the Epic Refinement lifecycle.

It supports consistent collaboration before Engineering-ready Epics enter the Engineering System for Engineering planning and governed realization.

---

# 2. Scope

This checklist applies to all Epic Refinement activities governed by the Collaboration System.

---

# 3. Review Checklist

## Product Context

- [ ] An Epic Refinement Record has been created.
- [ ] Product-approved Draft Epic(s) have been identified.
- [ ] Supporting Product artifacts have been referenced.
- [ ] Engineering Transition Record has been referenced.
- [ ] Product and Engineering representatives have been identified.

---

## Shared Understanding

- [ ] Approved business intent has been preserved.
- [ ] Product-approved Draft Epic(s) have been reviewed.
- [ ] Expected business outcomes have been confirmed.
- [ ] Product priorities have been understood.
- [ ] Significant assumptions have been reviewed.

---

## Epic Refinement

- [ ] Engineering-ready Epic has been defined.
- [ ] Epic boundaries have been collaboratively refined.
- [ ] Engineering observations have been documented.
- [ ] Engineering considerations have been incorporated.
- [ ] Significant dependencies have been identified.
- [ ] Significant engineering risks have been identified.
- [ ] Open questions have been documented.

---

## Collaboration

- [ ] Product representatives actively participated.
- [ ] Engineering representatives actively participated.
- [ ] Significant concerns have been discussed.
- [ ] Shared understanding has been maintained throughout refinement.
- [ ] Governed Agreements have been recorded.
- [ ] Required follow-up actions have been identified.

---

## Traceability

- [ ] Product-approved Draft Epic(s) have been referenced.
- [ ] Engineering Transition Record has been referenced.
- [ ] End-to-end traceability has been preserved.
- [ ] Related Collaboration records have been identified where applicable.

---

## Engineering Readiness

- [ ] Entry criteria have been satisfied.
- [ ] Exit criteria have been satisfied.
- [ ] The Epic Refinement outcome has been recorded.
- [ ] Product has acknowledged the Epic Refinement outcome.
- [ ] Engineering has acknowledged the Epic Refinement outcome.
- [ ] Engineering-ready Epic is ready to enter the Engineering System.

---

## Governance

- [ ] Collaboration followed the Collaboration Principles.
- [ ] Product ownership has been preserved.
- [ ] Engineering responsibilities have been fulfilled.
- [ ] Shared responsibilities have been fulfilled.
- [ ] Human accountability has been maintained.
- [ ] Governed Agreements have been recorded.
- [ ] The Epic Refinement Record is complete.

---

# 4. Review Outcome

| Result | Status |
|---------|--------|
| Engineering-ready Epic | |
| Engineering-ready Epic with Follow-up Actions | |
| Further Refinement Required | |

# 5. Review Comments

Document observations, recommendations or follow-up actions identified during the review.
