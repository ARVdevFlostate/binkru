# Release Readiness Checklist

## Purpose

Use this checklist to support evaluation of Release Readiness for an identified Release Candidate and defined progression or exposure context.

Completion of this checklist does not itself establish Release Readiness.

Release Readiness is established only through the applicable governed Release Readiness Decision and authority.

---

## Candidate and Context

- [ ] Applicable Release is identified.
- [ ] Release Candidate Identity is identified.
- [ ] Applicable Release Fingerprint is identified.
- [ ] Candidate Integrity is established or supported by applicable evidence.
- [ ] Progression purpose is determinable.
- [ ] Progression or exposure context is determinable.
- [ ] Applicable Release Exposure Context is identified where relevant.

## Governing Basis

- [ ] Applicable admitted Release scope is determinable.
- [ ] Applicable Release Admission determinations are traceable.
- [ ] Applicable Engineering basis is traceable.
- [ ] Applicable Product intent is traceable where required.
- [ ] Applicable Capability Acceptance is traceable where required.
- [ ] Applicable governing policies and constraints are identified.

## Conditions

- [ ] Applicable progression conditions are identified.
- [ ] Condition applicability to this candidate, fingerprint, and context has been established.
- [ ] Required conditions have been evaluated.
- [ ] Unsatisfied conditions are explicit.
- [ ] Applicable exceptions are explicit and governed.
- [ ] Applicable deviations are explicit.
- [ ] Material unresolved issues are explicit.

## Evidence

- [ ] Applicable Release Evidence is identified.
- [ ] Evidence is traceable to the applicable candidate and fingerprint.
- [ ] Evidence applicability to the progression or exposure context is determinable.
- [ ] Evidence provenance is determinable.
- [ ] Reused evidence has been assessed for continued applicability.
- [ ] Upstream evidence retains its originating ownership and provenance.
- [ ] Material evidence limitations are explicit.

## Candidate Change and Reassessment

- [ ] No material candidate change has invalidated the current readiness basis.
- [ ] Any fingerprint change has been evaluated for impact.
- [ ] Candidate replacement has triggered applicable reassessment.
- [ ] Material transformation has triggered applicable reassessment.
- [ ] Changed conditions or context have triggered applicable reassessment.
- [ ] Prior Release Readiness has not been silently reused where reassessment is required.

## Recovery or Prior Progression

Where applicable:

- [ ] Relevant prior Release Outcomes are identified.
- [ ] Recovery history affecting this progression is identified.
- [ ] Prior progression evidence has been assessed for continued applicability.
- [ ] Prior progression success has not been treated as automatic readiness for this progression.

## Exceptions, Deviations, and Emergency Governance

Where applicable:

- [ ] Release Exceptions are explicit and within their governed scope.
- [ ] Release Deviations are explicit.
- [ ] Emergency governance is explicitly established.
- [ ] Emergency authority is determinable.
- [ ] Emergency readiness conditions are determinable.
- [ ] Emergency evidence modifications are explicit.
- [ ] Applicable Release Readiness remains required before Release Authorization.

## Readiness Decision Preparation

- [ ] Applicable Release Candidate and Fingerprint are unambiguous.
- [ ] Progression or exposure context is unambiguous.
- [ ] Applicable conditions are determinable.
- [ ] Applicable evidence is determinable.
- [ ] Applicable exceptions and deviations are determinable.
- [ ] Unresolved conditions are explicit.
- [ ] Applicable Release Readiness authority is determinable.
- [ ] Decision basis and rationale can be preserved.
- [ ] Decision provenance can be preserved.

---

## Readiness Boundary

This checklist supports Release Readiness evaluation.

It SHALL NOT itself:

- establish Release Readiness;
- establish Release Authorization;
- authorize Release Promotion;
- establish Release Outcome;
- establish Released State; or
- redefine Product or Engineering truth.
