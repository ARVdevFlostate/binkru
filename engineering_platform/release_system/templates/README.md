# Release System Templates

This directory contains reusable templates supporting governed Release System activity.

Templates provide practical representations of semantics established by authoritative Release System specifications.

Templates are not independent sources of Release semantics, governance, authority, lifecycle state, or conformance requirements.

Where a template conflicts with an authoritative Release specification, the authoritative specification governs.

Templates MAY be adapted to project-specific representation needs provided the adaptation preserves applicable Release semantics, authority boundaries, traceability, provenance, and conformance obligations.

The Platform does not require every Release to populate every template field or section.

Applicability is determined by the governed Release context.

## Available Templates

### `release_record_template.md`

Provides a reference structure for progressively maintaining the authoritative Release Record.

The template supports preservation of:

- Release identity and governing basis;
- Release Admission and admitted Release scope;
- Release Candidate and Fingerprint history;
- Release Progression;
- Release Evidence;
- Release Readiness;
- Release Authorization;
- Release Promotion;
- Release Outcome;
- Released State where applicable;
- candidate replacement and material transformation;
- reassessment;
- Release Recovery;
- governed return to Engineering;
- exceptions and deviations;
- emergency Release governance;
- Release Conclusion;
- Release Record finalization; and
- post-finalization correction.

Use of the template does not itself establish any governed Release decision, state, authority, outcome, or conclusion.
