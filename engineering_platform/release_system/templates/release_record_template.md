# Release Record Template

## Usage

This template provides a representation-neutral starting structure for a Release Record.

The Release Record is progressively maintained throughout the Release Lifecycle and finalized only after Release Conclusion has been established.

Sections and fields SHALL be completed where applicable to the Release.

Sections that are not applicable MAY be omitted or identified as not applicable.

Use of this template does not itself establish Release authority, decisions, states, outcomes, or conclusions.
